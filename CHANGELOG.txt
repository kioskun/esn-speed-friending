ESN SPEED FRIENDING - CHANGES
=============================

For the event: download the latest zip from the GitHub repository's Releases
(or open current\speed-friending-esn.html in this folder). See README.md.

How versions work now
  - Every change is saved in git (GitHub keeps the full history), so there are
    no numbered copies any more. The old v1-v7 copies are in archive\versions\.
  - A new download is made by tagging a version (e.g. v8.2) and pushing the
    tag: GitHub builds the zip and publishes it under Releases.
  - Edit only current\ (the app), phone-remote\, feedback-form\.
  - archive\ stays on this computer / Drive only (too large for GitHub).
