ESN SPEED FRIENDING - FILES AND VERSIONS
========================================

OPEN THIS FOR THE EVENT:
  current\speed-friending-esn.html

Folders
  current\    The version in use. The app plus everything it loads (assets\, Badges\).
              All changes are made here, and only here.
  versions\   Numbered snapshots of earlier versions of the app (HTML only).
              v7 is saved as versions7-bigger-operator-window.html.
              To go back to one: copy it into current\ and rename it to
              speed-friending-esn.html (keep a copy of the current file first).
  archive\    Old material that is not used, kept just in case:
              - esn-speed-friending-v3.zip (old archive)
              - bg-original-3h.mp3 (the full 3-hour music mix; the app now uses a 30-minute loop)
              - v4-separate-rewrite-not-used\ (a separate rewrite made elsewhere, not used)

How new versions are made
  Before every change, the current file is copied into versions\ as the next number.

Versions (all 28/09/2026)
  v1  Original app as it was.
  v2  Sounds fixed (silent ticks, cut-off end bell, sounds turning into beeps),
      Esc opens Settings, moving stage-light background, rotation cards per badge
      colour, random moves that don't overwrite Settings, table numbers,
      date/time/venue in Settings, save progress across refresh, breaks stop timers,
      duplicate audio files removed.
  v3  Fixed-move mode removed (always random), arrow keys for intro screens,
      reset went to Welcome.
  v4  Seating first, badges handed out at the table, conversation-starters screen,
      H hint on Welcome.
  v5  Large operator panel and separate operator window, reset goes to round 1
      (Get Seated), 30-minute music loop.
  v6  Bug hunt: one stop-all-timers path (W W, reset and countdown no longer run
      on in the background), M mute, R rotate, L lock, Settings inside the operator
      window, held keys don't repeat, last-round and break fixes. Fully key-tested.
  v7  Bigger operator window so Settings fits without scrolling; the
      window opens as soon as you switch to it in Settings. Files reorganised.
  v8  (current) Nobody meets the same person twice: random moves that never
      repeat a meeting, remembered through the warm-up reset and refreshes
      (Settings shows how many rotations the table count allows, and has a
      Clear seating history button). Feedback form link in Settings, shown as
      a QR on the Thank you screen (made offline, hidden when empty).
      Tests in tests\, feedback form script in feedback-form\, README.md.
